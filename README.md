TrackSheet Website

This folder contains a lightweight, animated landing page to showcase the TrackSheet app.

Folder Structure
- index.html — Main page
- styles.css — Styling (responsive, dark, animated)
- script.js — GSAP-powered interactions and scroll animations
- assets/ — Add your logo and screenshots here

Getting Started
1) Place your logo at: website/assets/logo.png
2) Place app screenshots at:
   - website/assets/screenshots/01.png
   - website/assets/screenshots/02.png
   - website/assets/screenshots/03.png
   - website/assets/screenshots/04.png
   - website/assets/screenshots/05.png
3) Open index.html in a browser.

Customization
- Update contact links in the Contact section of index.html.
- Change theme colors in styles.css under the :root variables.
- Adjust animation timings/offsets in script.js.

Notes
- Uses GSAP + ScrollTrigger via CDN; no build step required.
- The bottom navbar highlights the current section and animates an indicator.
- Ensure images are optimized for web (PNG/JPEG/WebP).
